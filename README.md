# Backward Clock V6

V6 is based on the working V4 build. The lock-screen/show design and three fixed small widgets remain from V4. The only major UI change is the entry screen, restored to the simple V1/V2-style flow: choose a starting time, choose a wallpaper once, optionally prepare the camera, then start the show.

Wallpaper settings remain stored on the device. Widget configuration remains in the V4 settings panel.
