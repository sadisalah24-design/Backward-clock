# Backward Clock V6

V6 keeps the lock-screen presentation from V5 but restores the simple V1/V2-style entry flow.

- Entry screen: real-time preview, rewind amount and wallpaper selection.
- Wallpaper persists locally after the first selection.
- Exactly three small widgets are shown under the clock.
- Widget choices remain configurable from the separate Widget'ları düzenle screen.
- Starting the show closes setup and runs the reverse-clock animation.
- PWA/standalone configuration remains enabled.
